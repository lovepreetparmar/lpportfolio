# Character assets

Replace placeholder SVG with your illustrated frames.

## Recommended layout

```text
character/
  hero/
    idle.webp
    blink.webp
    look-left.webp
    look-right.webp
    look-up.webp
    look-down.webp
  frames/           (optional sequence)
    000.webp
    ...
```

## Reference photo

Use `images/all/bg1_new.jpg` from the legacy repo (or a new photo you provide) only as **illustration reference** — do not publish the raw photo as the hero.

## Formats

WebP or AVIF, responsive widths, lazy-loaded after hero.
